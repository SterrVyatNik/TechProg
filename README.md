# Лабораторная работа № 1 — сбор сведений об ОС

Скрипт определяет, в какой операционной системе он запущен, собирает основные сведения о системе и сохраняет их в JSON-файл рядом со скриптом.

Поддерживаются:
- Windows
- Linux
- macOS

## Запуск

Для работы нужен Python 3. Внешние библиотеки устанавливать не требуется.

Запуск в Windows:

```bash
python my_script.py
```

В Linux и macOS:

```bash
python3 my_script.py
```

Если в Windows используется Python Launcher:

```powershell
py my_script.py
```

## Собираемые сведения

Скрипт получает:

- дату и время сбора информации;
- название операционной системы;
- версию системы;
- архитектуру системы;
- имя компьютера;
- количество логических процессоров;
- сведения о диске;
- версию Python.

После выполнения информация сохраняется в JSON-файл.

## Используемые модули

В программе используются только модули стандартной библиотеки Python:

- `sys`
- `os`
- `socket`
- `shutil`
- `datetime`
- `pathlib`
- `json`

Дополнительные библиотеки устанавливать не требуется.

## Структура репозитория

- `my_script.py` — основной скрипт лабораторной работы;
- `README.md` — описание программы и инструкция по запуску;
- JSON-файлы — результаты запуска программы в разных операционных системах.

## Проверка

Для проверки необходимо запустить скрипт в нужной операционной системе и убедиться, что программа создаёт JSON-файл с информацией о системе.
